# D2C Sales Dashboard 2025

## Project Overview
This Power BI dashboard analyzes Direct-to-Consumer (D2C) sales performance for 2025.

## Key Metrics
- Total Sales Revenue: 29M
- Total Orders: 17.3K
- Total Quantity Sold: 42K
- Total Customers: 12.5K

## Dashboard Features
- Sales by Category
- Sales by Channel
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by City Tier
- Interactive Filters (Month & Category)

## Tools Used
- Power BI
- Power Query
- Data Modeling
- DAX
- Data Visualization

## Insights
- Skincare generated the highest sales.
- Sales consistently increased from January to July.
- Metro cities contributed the majority of revenue.
